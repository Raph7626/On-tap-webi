# SD React

Ba app React được tạo trong thư mục này:

- `TaskManager` — Quản lý nhiệm vụ.
- `KTXManager` — Quản lý phòng ký túc xá.
- `StudentManager` — Quản lý sinh viên.

Mỗi app là một project `vite` độc lập. Để chạy app nào, mở terminal trong thư mục tương ứng và thực hiện:

```bash
npm install
npm run dev
```

Sau đó truy cập URL mà `vite` cung cấp.
